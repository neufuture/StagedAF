✦ UnitStager Virtual staging for AppFolio

Image model

UnitStager sends photos straight from your browser to the image service using your own API key. The key is stored only in this browser.

Advanced

Staging

{room} and {style} are filled in per photo. Instructions typed for a specific photo are added after this prompt.

Behaviour

Image host access

Only needed if staging an existing photo fails with “can't download photos from …”. Enter that host to let UnitStager read photos from it.

AppFolio page detection

Leave these blank to auto-detect. If Stage buttons don't appear, or replacing can't find the upload or delete control, use “Copy page diagnostics” in the UnitStager panel on that page to work out the right CSS selectors.
