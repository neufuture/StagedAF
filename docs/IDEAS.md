# Ideas for later

Not built yet. Kept here so they aren't lost.

## Owner tags in the extension

When staging a photo in AppFolio, let the user pick or create a tag such as
"Property LLC" (the owner company the unit belongs to), and remember it per
property or unit. Each staging is then recorded against that tag, so credits
used can be totalled per owner and billed back to them. Likely needs: a tag
field on each staging record on the server, a tag picker in the extension's
Stage popover (remembering the last tag used for that property), and a
per-tag usage report on the website's Account page (exportable as CSV).

## Saved prompt / settings sets

In the website studio (and the extension), save a named combination of style,
room defaults and instructions — e.g. "Luxury units: transitional, warm
neutrals, no TV" — and apply it in one click. Store sets on the account so
they follow the user between the website and the extension.
